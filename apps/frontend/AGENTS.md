# Local Rules: Frontend (`apps/frontend/AGENTS.md`)

## 1. Назначение директории
Данный модуль содержит клиентскую витрину каталога и административную панель на базе **Next.js 15+ (App Router)**, **React 19**, **TypeScript** и **shadcn/ui**.

## 2. Локальные правила для Frontend Agent
- **Терминология UI:** Строжайшее соблюдение терминологии:
  - Использовать: **"Моя подборка"**, **"В подборку"**, **"Отправить запрос"**.
  - Запрещено использовать: "Корзина", "Cart", "Купить", "Оформить заказ", "Checkout".
- **Интеграция с API:** Все сетевые вызовы типизируются согласно `docs/api/openapi.yaml`. Использовать нативный `fetch` с кэшированием Next.js для SSR/SSG.
- **Хранилище подборки:** Zustand с middleware `persist` (`localStorage`). Обязательна тихая валидация доступности товаров при монтировании компонента подборки (скрытые товары помечаются серым).
- **Стилизация и компоненты:**
  - Строго TailwindCSS и примитивы `shadcn/ui`.
  - Запрещено подключать тяжелые сторонние библиотеки UI (MUI, Ant Design).
  - Адаптивный дизайн: Mobile-first (свайп-галерея, шторки фильтров, sticky-кнопка "В подборку").
- **Админ-панель (`/admin`):**
  - Реализуется как Client-Side Rendering (CSR) с изолированным Layout.
  - Поллинг новых заявок раз в 30 секунд.
  - Редактор товара — единая форма с предварительной загрузкой фото в Cloudinary.
- **Запреты:**
  - Запрещено модифицировать файлы в `apps/backend/` или `database/`.
  - Запрещено сохранять JWT токен в `localStorage` админки (строго HttpOnly Cookie).
