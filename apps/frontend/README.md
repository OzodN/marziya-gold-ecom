# Frontend Application Placeholder (`apps/frontend`)

## Стек
- Next.js 15+ (App Router)
- React 19
- TypeScript
- TailwindCSS
- shadcn/ui
- Zustand (с `persist` в `localStorage`)

## Правила
Ознакомьтесь с [AGENTS.md](AGENTS.md) перед началом работы.
Соблюдайте утвержденную терминологию: "Моя подборка", "В подборку", "Отправить запрос".
Никаких e-commerce элементов (корзина, оплата, остатки).
Клиентская часть разрабатывается назначенным агентом `frontend` в рамках выделенных задач.
