# Local Rules: Backend (`apps/backend/AGENTS.md`)

## 1. Назначение директории
Данный модуль содержит серверную часть приложения на базе **Java 21 LTS** и **Spring Boot 4.1.1**.

## 2. Локальные правила для Backend Agent
- **Контракт API:** Реализация контроллеров строго следует спецификации `docs/api/openapi.yaml`. Если требуется изменить контракт, это делается через Оркестратора и согласование с Frontend.
- **Схема БД:** Все изменения схемы оформляются в виде миграций Flyway (`src/main/resources/db/migration/`). Режим JPA `hibernate.ddl-auto` строго установлен в `validate` или `none`.
- **Архитектурный стиль:** Слоистая архитектура (Controller -> Service -> Repository). Контроллеры оперируют DTO, а не JPA-сущностями.
- **Безопасность:**
  - JWT выдается и принимается через `HttpOnly` Cookie.
  - Публичный эндпоинт отправки заявок защищен `Bucket4j` rate limiting.
- **Тестирование:**
  - Использовать JUnit 5 (`junit-5-skill`), Mockito, AssertJ.
  - Обязательно покрывать негативные сценарии (валидация, неавторизованный доступ).
- **Запреты:**
  - Запрещено модифицировать файлы в `apps/frontend/`.
  - Запрещено хранить загруженные медиафайлы на локальном диске (только Cloudinary).
