# Канонические критерии качества UX/UI (UX/UI Design & Experience Criteria)

Данный документ является единственным каноническим источником истины для оценки дизайна, пользовательского опыта и эргономики витрины и панели управления каталога `marziya-gold_ecom`. Все фронтенд-компоненты и пользовательские сценарии обязаны строго соответствовать данным критериям для прохождения `ux_review_gate`.

---

## 1. Концепция и визуальный язык (Luxury Minimalist Aesthetic)

1. **Цветовая палитра и контраст:**
   - **Фон:** Чистый белый (`#FFFFFF`), премиальный молочный/слоновая кость (`#FAFAF9` / `bg-stone-50`) для контраста секций.
   - **Текст:** Глубокий темный графит (`#1C1917` / `text-stone-900`) для максимальной читаемости без едкого чистого черного.
   - **Акценты бренда:** Благородное приглушенное золото/бронза (`#D97706` / `#B45309` / `text-amber-600/700`) для акцентных лейблов, бейджей и активных элементов.
   - **Границы и разделители:** Тонкие, деликатные линии (`border-stone-200 / border-stone-100`). Запрещены тяжелые толстые рамки.
2. **Типографика:**
   - Заголовки: Элегантный премиальный serif/sans-шрифт с благородным трекингом (`tracking-wide` / `tracking-wider`).
   - Основной текст: Нейтральный, легко читаемый гротеск (Inter / Geist / system sans).
   - Иерархия размеров: Строгая градация (h1 > h2 > h3 > body > caption). Запрещено использовать более 3 размеров шрифта в одном компактном блоке.
3. **Визуальный «воздух» (Whitespace):**
   - Просторные отступы вокруг карточек изделий, между характеристиками и вокруг кнопок действий. Изделия не должны казаться «слипшимися».

---

## 2. Матрица обязательных состояний компонентов (Component State Matrix)

Каждый интерактивный компонент и страница каталога обязаны реализовывать 6 обязательных состояний:

| Состояние | Требования к реализации | Антипаттерны (Запрещено) |
|---|---|---|
| **Default** | Четкая визуальная иерархия, интуитивная доступность для клика/тапа. | Неочевидность кликабельности элемента. |
| **Hover / Focus** | Деликатное изменение яркости/тени (`transition-all duration-200`), видимый focus-ring для клавиатурной навигации (`focus-visible:ring-2`). | Резкие скачки размеров, отсутствие фокус-индикаторов. |
| **Loading** | **Content-aware Skeleton** (анимированные серые блоки по форме контента). Позволяет избежать сдвига макета (CLS). | Полноэкранный блокирующий спиннер, пустое белое окно во время загрузки. |
| **Empty** | Дружелюбная заглушка с понятным сообщением и действием (CTA), например: *"В вашей подборке пока нет изделий"* + кнопка `[ Перейти в каталог ]`. | Пустой экран, ломающий верстку; дефолтная ошибка 404. |
| **Error** | Локализованные понятные подсказки валидации красным цветом под полями ввода без скачков верстки. | Системные алерты браузера (`alert()`), непонятные коды ошибок ("Error 500"). |
| **Disabled** | Полупрозрачность (`opacity-50`), отключенный курсор (`cursor-not-allowed`), подсказка о причине неактивности при необходимости. | Элемент выглядит активным, но не реагирует на нажатия. |

## 3. Mobile-First Эргономика (Смартфоны и Планшеты)

1. **Правило большого пальца (Thumb Zone):**
   - Все ключевые интерактивные элементы (кнопка добавления в подборку, счетчик количества, вызов фильтров) должны находиться в нижней или средней зоне экрана, доступной для управления одной рукой.
2. **Размер областей нажатия (Touch Targets):**
   - Минимальный размер кликабельной области для любых кнопок и иконок — **44 × 44 CSS пикселя** (регламент Apple HIG / Android Material).
   - Запрещены мелкие иконки без увеличенного паддинга (`p-2` / `min-h-[44px] min-w-[44px]`).
3. **Липкая нижняя панель (Sticky Action Bar):**
   - На странице товара (`/product/[slug]`) при прокрутке длинного описания и характеристик внизу экрана фиксируется компактная панель с кнопкой **"В подборку"** и счетчиком количества.
4. **Мобильные шторки (Bottom Sheets / Drawers):**
   - Фильтры каталога и просмотр подборки на мобильных устройствах открываются в виде нижней всплывающей шторки (Drawer), а не модального окна по центру экрана.
5. **Галерея и жесты:**
   - Поддержка нативных горизонтальных свайпов между фотографиями изделия с индикатором-точками (dots pagination).
   - Зум фотографий по тапу/щепотке без искажения пропорций.

## 4. Строгий словарь и терминология UI (Terminology Enforcement)

| Утвержденный термин | Категорически запрещено | Контекст использования |
|---|---|---|
| **Моя подборка** | Корзина, Cart, Заказ, Basket | Название раздела и боковой панели с выбранными товарами. |
| **В подборку** | В корзину, Купить, Добавить в заказ | Главная кнопка на карточке товара. |
| **Отправить запрос** | Оформить заказ, Купить в 1 клик, Checkout | Кнопка отправки формы заявки мастеру. |
| **Связаться с мастером** | Написать продавцу, Техподдержка | Блок прямых контактов ([Telegram], [Позвонить]). |
| **Изделие изготавливается под заказ** | Нет в наличии, Под заказ (сухо), Доступно 0 шт | Пояснение об отсутствии склада и индивидуальном производстве. |

## 5. Доступность и качество взаимодействия (Accessibility & Interaction)

1. **Клавиатурная навигация:**
   - Любая модалка или шторка обязана закрываться по клавише `Escape` и по клику на оверлей/бэкдроп.
   - Внутри открытых диалогов должен удерживаться фокус (Focus Trap), чтобы фокус не улетал под бэкдроп.
2. **Экранные дикторы (Screen Readers):**
   - Все кнопки-иконки (крестик закрытия, иконка лупы, кнопки `+` и `-`) обязаны содержать понятный `aria-label` (например, `aria-label="Увеличить количество"`).
3. **Предотвращение потери данных:**
   - Состояние подборки клиента сохраняется в `localStorage` (Zustand persist).
   - При наличии в подборке архивного или скрытого товара, товар отображается приглушенным с плашкой *"Изделие больше недоступно"* (с возможностью удалить его), но не удаляется молча без ведома клиента.
