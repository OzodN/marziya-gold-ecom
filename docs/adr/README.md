# Architecture Decision Records (ADR)

## 1. Канонический статус
Директория `docs/adr/` является **единственным каноническим местом хранения архитектурных решений** в репозитории `marziya-gold_ecom`. Любые дублирующие каталоги или записи в кодовой базе запрещены.

## 2. Формат записи ADR
Каждая запись именуется по маске `NNNN-<kebab-case-title>.md` (например, `0001-baseline-architecture-decisions.md`) и содержит:
- **Title**: Номер и краткое название решения.
- **Status**: `Proposed` | `Accepted` | `Deprecated` | `Superseded by ADR-XXXX`.
- **Date**: Дата принятия решения.
- **Context**: Описание проблемы, предпосылок и ограничений.
- **Decision**: Суть принятого решения.
- **Consequences**: Положительные и отрицательные последствия.
- **Alternatives Considered**: Рассмотренные альтернативы и причины отказа от них.
