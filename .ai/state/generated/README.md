# Generated State Layer (`.ai/state/generated/`)

> **ВНИМАНИЕ ВСЕМ АГЕНТАМ:**
> Файлы в данной директории являются **автоматически сгенерированными производными артефактами** для оптимизации быстродействия агентов при первичном анализе кодовой базы.
> 
> **ОНИ СТРОГО НЕ ЯВЛЯЮТСЯ ИСТОЧНИКОМ ИСТИНЫ.**
> Если данные в сгенерированном JSON расходятся с каноническими манифестами (`.ai/work/registry.yaml`, `task.yaml`, `docs/api/openapi.yaml`, Flyway migrations) — истинными признаются только канонические файлы.
> 
> Любой файл в этой папке может быть перегенерирован скриптом `scripts/validate-ai-state.ps1`.
