# Словарь терминов и обязательные формулировки (Terminology)

## 1. Зафиксированная терминология UI/UX
- **"Моя подборка"** (Selection) — единственный правильный термин для списка выбранных изделий клиента (СТРОГО ЗАПРЕЩЕНО: "Корзина", "Cart", "Shopping Bag").
- **"В подборку"** (Add to Selection) — надпись на кнопке добавления изделия в карточке (СТРОГО ЗАПРЕЩЕНО: "Купить", "В корзину", "Buy now").
- **"Отправить запрос"** / **"Отправить заявку"** (Submit Inquiry) — действие оформления заявки (СТРОГО ЗАПРЕЩЕНО: "Оформить заказ", "Checkout", "Оплатить").
- **"Заявка"** (Inquiry / Request) — сущность запроса клиента в админ-панели (НЕ "Заказ" / "Order").
- **"Изделие"** / **"Товар"** (Product / Jewelry piece) — элемент каталога.
- **"Справочник характеристик"** (Characteristic Keys) — глобальный список имен параметров.
- **"Типы камней"** (Stone Types) — справочник минералов (Бриллиант, Сапфир и др.).

## 2. Термины статусов заявки
- `NEW` — Новая заявка, ожидает первого звонка/сообщения мастера.
- `CONTACTED` — Мастер связался с клиентом для уточнения деталей.
- `IN_PROGRESS` — Изделия запущены в работу/производство.
- `COMPLETED` — Изделия изготовлены и переданы клиенту, сделка закрыта.
- `REJECTED` — Отказ клиента или невозможность выполнения заказа.
