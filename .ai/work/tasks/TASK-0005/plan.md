# План реализации TASK-0005: Закрытие шторки «Моя подборка» по клику вне области и Escape

## 1. Цель задачи
Обеспечить интуитивное закрытие шторки (drawer) «Моя подборка»:
1. При клике на затемнённую область фона (backdrop) за пределами самой шторки вызывать `closeSelection()`.
2. При нажатии клавиши `Escape` на клавиатуре вызывать `closeSelection()`.
3. Сохранить невозможность случайного закрытия при кликах внутри тела шторки (выбор количества, удаление изделия, отправка запроса).

## 2. Архитектурный контекст и файлы
- Файл компонента: `apps/frontend/src/components/selection/SelectionSheet.tsx`
- Store: `apps/frontend/src/store/selection-store.ts` (`closeSelection`, `isOpen`)
- Владелец: `frontend`

## 3. Шаги выполнения
1. **Изоляция и ворктри:**
   - Создать рабочее дерево `.worktrees/TASK-0005-selection-sheet-backdrop` на ветке `feat/TASK-0005-selection-sheet-backdrop`.
2. **Модификация `SelectionSheet.tsx`:**
   - Добавить явный элемент оверлея / кликабельный бэкдроп с `onClick={closeSelection}`.
   - Изолировать внутренний контейнер шторки через `onClick={(e) => e.stopPropagation()}` и управление `pointer-events`.
   - Добавить `useEffect` с глобальным слушателем события `keydown`: при `event.key === 'Escape'` вызывать `closeSelection()`.
3. **Верификация:**
   - Запустить `npm run build` в `apps/frontend` и убедиться в отсутствии ошибок сборки и линтинга.
   - Проверить терминологию (отсутствие запрещенных слов).
4. **Оформление хендоффа и интеграция:**
   - Составить `.ai/work/tasks/TASK-0005/handoff.md`.
   - Влить ветку локально в `main` (без PR согласно указаниям пользователя) и удалить временное ворктри.
