# План реализации TASK-0008: Инициализация начальных данных (Seed Data)

## 1. Цель
Создать миграцию `V2__seed_initial_data.sql` для наполнения PostgreSQL начальными справочниками (категории, камни, характеристики), учетной записью администратора и демонстрационными ювелирными изделиями.

## 2. Объем данных
1. Администратор: `admin` / `admin123` (BCrypt).
2. Категории: Кольца, Серьги, Браслеты, Колье и подвески, Броши.
3. Характеристики: Металл, Проба, Вес изделия, Размер, Покрытие.
4. Камни: Бриллиант, Сапфир, Изумруд, Рубин, Жемчуг, Топаз.
5. Изделия (6 шт.) с реалистичными характеристиками, камнями и изображениями.
6. Системные настройки: контакты мастера (телефон, telegram, описание).
