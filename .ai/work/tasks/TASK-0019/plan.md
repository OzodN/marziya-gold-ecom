# План реализации TASK-0019: Каркас админ-панели, авторизация мастера и дашборд с polling

## 1. Цель задачи
Реализовать основу закрытой административной панели мастера ювелирных изделий:
- Экран входа мастера (`/admin/login`) с авторизацией по HttpOnly Cookie.
- Лейаут панели мастера с навигацией и проверкой прав (`/admin/layout.tsx`).
- Главный экран дашборда (`/admin/dashboard`) с карточками показателей и фоновым опросом новых заявок каждые 30 секунд (`GET /api/v1/admin/inquiries/new-count`).
- Процедура выхода (`logout`).

## 2. Объем реализации в `apps/frontend/`
1. **API клиент (`src/lib/admin-api.ts` или расширение `api.ts`):**
   - `adminLogin(username, password)` -> `POST /api/v1/admin/auth/login`
   - `adminLogout()` -> `POST /api/v1/admin/auth/logout`
   - `getAdminMe()` -> `GET /api/v1/admin/auth/me`
   - `getNewInquiriesCount()` -> `GET /api/v1/admin/inquiries/new-count`
2. **Экран входа (`src/app/admin/login/page.tsx`):**
   - Лаконичная форма в ювелирном стиле (Charcoal / Gold / Cream).
   - Поля: логин мастера, пароль, кнопка «Войти в панель».
   - Индикация загрузки, вывод понятных сообщений об ошибках (401 Bad Credentials, ошибка сети).
   - При успешном входе — переход на `/admin/dashboard`.
3. **Лейаут админ-панели (`src/app/admin/layout.tsx`):**
   - Защита маршрутов: клиентская проверка `getAdminMe()` при открытии (или middleware). Если не авторизован — редирект на `/admin/login`.
   - Верхняя или боковая навигационная панель:
     - Логотип и надпись: «Marziya Gold | Панель мастера»
     - Ссылки: «Дашборд», «Заявки», «Каталог изделий», «Категории», «Справочники», «Контакты»
     - Бейдж количества новых заявок (с анимацией при `count > 0`)
     - Кнопка «Выйти» с подтверждением
4. **Дашборд (`src/app/admin/dashboard/page.tsx`):**
   - Сводные карточки:
     - «Новые заявки»: живой счетчик, дата последней проверки, кнопка «Перейти к заявкам»
     - «Каталог изделий»: быстрый переход к изделиям и созданию изделия
     - «Витрина сайта»: быстрая ссылка на открытый каталог для проверки внешнего вида
   - Polling Hook: фоновый запрос `getNewInquiriesCount()` каждые 30 секунд.
   - Звуковой сигнал или ненавязчивое уведомление при поступлении новых заявок.

## 3. Валидация
- `npm run build` в `apps/frontend` завершается без ошибок.
- Проверка соответствия дизайну и UX критериям (`docs/design/ux-criteria.md`).
- Оформление отчета `handoff.md`.
