# План реализации TASK-0015: Интерактивный зум и панорамирование в лайтбоксе

## 1. Проблема
В режиме полноэкранного просмотра фотографий функция зума не увеличивала изображение:
1. Использовался несуществующий в Tailwind класс `scale-175`, из-за чего браузер не применял CSS трансформацию.
2. Обработчики перетаскивания (mouse drag) на общем контейнере конфликтовали с событиями клика мыши.
3. Отсутствовала возможность перемещаться (панорамировать / pan) по приближенному изображению изделия для детального осмотра камней и пробы.

## 2. Решение
1. В `ProductGallery.tsx` перейти на явные инлайн-стили `style={{ transform: ... }}` с аппаратным GPU-ускорением:
   - Масштабирование от 1x до 3.5x.
   - Клик по фото: быстрое переключение 1x <-> 2.2x.
   - Колесико мыши (`onWheel`): плавный зум вперед/назад.
   - Панорамирование (Pan): при `scale > 1` перетаскивание мышью плавно двигает приближенную фотографию в границах экрана.
   - При `scale === 1` перетаскивание листает соседние фотографии.
2. Кнопки управления в верхней панели:
   - Кнопка `[-]` (уменьшить) с шагом 0.4x (минимум 1x).
   - Индикатор масштаба в процентах (например, `100%`, `220%`).
   - Кнопка `[+]` (увеличить) с шагом 0.4x (максимум 3.5x).
   - Кнопка `[Сбросить]` для быстрого возврата к 100%.
3. Автоматический сброс масштаба и смещения при смене кадра и закрытии окна.
4. Валидация через `npm run build`.
