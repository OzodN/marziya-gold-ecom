# План реализации TASK-0011: Детальная страница карточки изделия /product/[slug]

## 1. Цель задачи
Реализовать полноценную страницу ювелирного изделия ручной работы в соответствии с `docs/architecture/product-architecture.md` (раздел 5) и `docs/design/ux-criteria.md`.

## 2. Структура компонентов
1. `ProductGallery.tsx`:
   - Главное фото с плавной сменой при клике на миниатюру.
   - Полноэкранный зум/модалка при клике на фото.
   - Поддержка свайп-жестов на мобильных устройствах.
2. `ProductInfo.tsx`:
   - Название, SKU, категория (бейдж-ссылка).
   - Подробное описание.
   - Таблица динамических характеристик (Металл, Проба, Вес изделия, Размер).
   - Карточки состава камней (Бриллиант, Изумруд, Сапфир с каратностью и огранкой).
   - Счетчик количества и кнопка «В подборку».
   - Блок прямых контактов мастера ([Telegram] и [Позвонить]).
3. `StickyActionBar.tsx`:
   - Липкая нижняя панель на экранах смартфонов (<640px) с миниатюрой, названием, счетчиком и кнопкой «В подборку».
4. `src/app/product/[slug]/page.tsx`:
   - Серверный компонент с `generateStaticParams()` и `generateMetadata()`.
   - Внедрение Schema.org `Product` JSON-LD.
   - Хлебные крошки (Главная -> Каталог -> [Категория] -> [Изделие]).

## 3. Валидация
- `npm run build` (проверка генерации всех статических страниц изделий).
- Проверка терминологии.
