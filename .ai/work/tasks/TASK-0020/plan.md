# План реализации TASK-0020: Admin Inquiries Management UI with Historical Snapshot and Status Audit

## 1. Цель задачи
Реализовать интерфейс управления входящими заявками клиентов в закрытой панели мастера ювелирных изделий:
- Список заявок (`/admin/inquiries`) с фильтрацией по статусам, пагинацией и поиском по клиенту.
- Детальный экран заявки (`/admin/inquiries/[id]`) с контактами клиента, неизменяемым слепком заказанных изделий (snapshot), блоком ручной смены статуса и историей аудита изменений.

## 2. Объем реализации в `apps/frontend/`
1. **API клиент (`src/lib/admin-api.ts`):**
   - `getAdminInquiries(page, size, status)` -> `GET /api/v1/admin/inquiries`
   - `getAdminInquiryById(id)` -> `GET /api/v1/admin/inquiries/{id}`
   - `updateAdminInquiryStatus(id, status)` -> `PUT /api/v1/admin/inquiries/{id}/status`
2. **Экран списка заявок (`src/app/admin/inquiries/page.tsx`):**
   - Вкладки фильтрации: «Все», «Новые», «Связались», «В работе», «Завершены», «Отклонены».
   - Таблица/список заявок: ID, дата поступления, имя клиента, телефон (с кликабельной ссылкой `tel:`), количество позиций, статус-бейдж (`NEW` - золотой/пульсирующий, `CONTACTED` - синий, `IN_PROGRESS` - янтарный, `COMPLETED` - изумрудный, `REJECTED` - нейтрально-серый), кнопка «Открыть».
   - Пагинация и индикаторы загрузки (скелетоны).
   - Empty state: дружелюбный экран «Нет заявок в данном статусе».
3. **Детальный экран заявки (`src/app/admin/inquiries/[id]/page.tsx`):**
   - Кнопка «← Назад к заявкам».
   - Заголовок с номером заявки и датой создания.
   - Блок контактов клиента: Имя, Телефон (с кнопками [Позвонить], [Скопировать]), опциональный Комментарий клиента.
   - Блок ручной смены статуса:
     - Селектор нового статуса.
     - Кнопка «Сохранить изменения» (активна только при изменении статуса).
     - Предупреждение о несохраненных изменениях.
   - Блок заказанных изделий (слепок snapshot):
     - Фотография изделия, название, артикул (SKU), количество (`quantity шт.`).
     - Динамические характеристики из снапшота (Металл, Проба, Вес и т.д.).
     - Состав камней из снапшота (Тип камня, параметры).
   - Таймлайн истории изменений статусов (Audit History):
     - Хронологическая шкала: кто изменил (`changedBy`), старый статус -> новый статус, точная дата и время.

## 3. Валидация
- `npm run build` в `apps/frontend` проходит без ошибок.
- UX аудит соответствия ювелирной эстетике и терминологии мастера.
