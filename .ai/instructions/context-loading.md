# Регламент загрузки контекста агентами (Context Loading Order)

Каждый агент перед началом работы обязан загрузить контекст в строго определенном порядке, чтобы не превысить лимит токенов и не упустить ключевые ограничения.

---

## 1. Обязательный порядок загрузки

1. **Базовые правила проекта:**
   - Чтение корневого файла `AGENTS.md`.
   - Чтение локального `AGENTS.md` своей рабочей директории (например, `apps/backend/AGENTS.md`).

2. **Источники истины и доменные ограничения:**
   - Чтение `.ai/instructions/source-of-truth.md`.
   - Чтение профильных контекстных файлов:
     - Все агенты: `.ai/context/project.md`, `.ai/context/terminology.md`, `.ai/context/constraints.md`, `.ai/context/non-goals.md`.
     - Backend & Database: `.ai/context/domain.md`, `docs/api/openapi.yaml`.
     - Frontend: `.ai/context/domain.md`, `docs/api/openapi.yaml`.
     - DevOps: `.ai/context/integrations.md`.

3. **Стек и навыки:**
   - Чтение `.ai/stack/aas-stack.json` для идентификации разрешенных глобальных навыков.
   - Активация только релевантных навыков через чтение `SKILL.md` (progressive disclosure).

4. **Задача и рабочее состояние:**
   - Чтение манифеста назначенной задачи `.ai/work/tasks/<TASK-ID>/task.yaml`.
   - Чтение плана задачи `plan.md` и входящего хендоффа (если задача зависит от предыдущей).

5. **Ограничения владения:**
   - Чтение `.ai/orchestration/ownership.yaml` для подтверждения списка файлов, разрешенных к изменению.

---

## 2. Запрещенные действия при загрузке контекста
- **ЗАПРЕЩЕНО** полностью загружать всю историю предыдущих диалогов.
- **ЗАПРЕЩЕНО** читать весь монолитный документ `docs/architecture/product-architecture.md`, если достаточно компактных файлов в `.ai/context/`.
- **ЗАПРЕЩЕНО** читать файлы директорий, принадлежащих другим агентам (например, Frontend-агенту читать исходники Java в `apps/backend/src/`), кроме интерфейсных контрактов (`openapi.yaml`).
