# Local Rules: Database (`database/AGENTS.md`)

## 1. Назначение директории
Данная директория предназначена исключительно для архитектурной документации базы данных, ER-диаграмм и руководств по индексации.

## 2. Локальные правила для Database Agent
- **Единственный источник истины:**
  - Истинной схемой базы данных являются SQL-миграции Flyway в директории:
    `apps/backend/src/main/resources/db/migration/`
  - В директории `database/` **СТРОГО ЗАПРЕЩЕНО** создавать конкурирующие файлы создания схемы (например, `schema.sql`, `init.sql`).
- **Документация:**
  - Файл `database/schema-model.md` является производной документацией и обязан обновляться синхронно с миграциями.
- **Особенности модели:**
  - PostgreSQL 16+.
  - Обязательно использование GIN-индексов для полей `characteristics` (JSONB).
  - Обязательно использование расширения `pg_trgm` и триграммных индексов по полям `name` и `sku`.
  - Позиции заявок (`inquiry_item`) хранят полный неизменяемый `product_snapshot` в JSONB.
- **Запреты:**
  - Запрещено выполнять изменения схемы в рабочей БД в обход Flyway.
  - Запрещено удалять или модифицировать уже примененные миграции в продакшене.
